# 黄师校园 · smarthgnu

面向黄冈师范学院的非官方 Android 校园客户端，提供校园账号登录、原生课表和校园服务入口。

使用 Java 与原生 Android View 独立实现，包名为 `com.smart.hgnu`，可与学校官方客户端并存。

**当前版本：0.2.2 预览版 · Android 6.0 及以上**

[下载最新发布版](https://github.com/efface-yyy/huangshi-xiaoyuan/releases/tag/v0.2.2) · [查看服务适配清单](app/SERVICE_AUDIT.md) · [反馈问题](https://github.com/efface-yyy/huangshi-xiaoyuan/issues)

## 下载与使用

1. 在 Release 页面下载 `smarthgnu-0.2.2.apk` 并安装。
2. 使用校园账号登录，等待资料、服务目录和课表同步完成。
3. 在底部导航切换校园首页、课表、服务和个人页面。

应用需要能够访问学校服务器。服务内容及可用范围随账号权限、学校配置和网络环境变化。

## 已有功能

### 账号与校园首页

- 校园账号登录，在手机端完成协议所需的密钥协商和请求加密。
- 使用 Android Keystore 与 AES-GCM 加密保存会话，重启后自动恢复，不保存登录密码。
- 展示校园概览、个人身份和数据同步状态，个人资料页对手机号进行遮罩。
- 支持下拉刷新及“我的 → 重新同步数据”；退出登录时清理本机会话和内嵌网页存储。

### 原生课表

- 支持学期、教学周选择，以及返回本周。
- 根据学校校历和服务器时间计算教学周。
- 提供周表格和列表两种视图，切换列表时默认选中当天。
- 同一课程保持同色，课程地点支持换行与字号适配；点击可查看完整课程信息。
- 按日期切换冬春、夏秋作息，显示具体上课时间。

### 校园服务

**服务功能基本适配。** 服务页使用学校按账号下发的正式目录，按分类展示，并支持名称、描述和分类关键词搜索。

- 轻应用通过学校登录跳板进入，支持已有校园会话的单点登录。
- 课表入口进入本 App 的原生课表；“成绩排名”提供原生查询入口。
- 网页已接入系统文件选择器，支持单选、多选及文件类型筛选。
- 服务网页和原生成绩页使用统一的浅绿色圆角返回按钮。

已在 Pixel 10 Pro XL 模拟器检查学生请假申请、事务中心、我的图书馆、图书馆座位预约、图书馆检索、空闲教室、通知公告、发票助手等入口。测试账号下发的目录共 40 项，逐项结果见 [服务适配清单](app/SERVICE_AUDIT.md)。

**页面能够打开，不代表业务全流程已经验证。** 目前的检查以页面加载、登录状态和表单展示为主，没有提交申请、预约或支付数据。

## 本地开发

仓库根目录就是 Android 工程，可直接使用 Android Studio 打开。

| 配置 | 版本 |
| --- | --- |
| 开发语言 | Java 11 |
| Android Gradle Plugin | 7.4.2 |
| Gradle Wrapper | 7.6 |
| compileSdk / targetSdk | 33 |
| minSdk | 23（Android 6.0） |

安装 JDK 11 和 Android SDK 33，配置本机 `local.properties` 后构建：

```powershell
.\gradlew.bat assembleDebug
```

macOS / Linux 使用 `sh ./gradlew assembleDebug`。调试包输出到 `app/build/outputs/apk/debug/app-debug.apk`。

```text
app/
├── src/main/java/com/smart/hgnu/  # 页面、状态、网络协议与会话管理
├── src/main/res/                 # 主题、图标和网络安全配置
├── src/test/                    # 服务路由逻辑检查
├── SERVICE_AUDIT.md              # 服务逐项适配状态
└── build.gradle
gradle/wrapper/                   # Gradle Wrapper
```

### 签名构建

通过环境变量提供签名配置，不要将密钥或密码写入仓库：

| 环境变量 | 内容 |
| --- | --- |
| `HGNU_KEYSTORE_PATH` | 密钥库绝对路径 |
| `HGNU_STORE_PASSWORD` | 密钥库密码 |
| `HGNU_KEY_ALIAS` | 签名别名 |
| `HGNU_KEY_PASSWORD` | 私钥密码 |

```powershell
.\gradlew.bat assembleRelease lintRelease
```

配置签名后生成 `app/build/outputs/apk/release/app-release.apk`；未配置时生成未签名产物。自行签名的 APK 只有与已安装版本签名一致时，才能覆盖升级。

0.2.2 已通过发布构建、Lint 和签名校验；页面检查使用 Android Studio 的 Pixel 10 Pro XL。具体业务验证范围以上方状态说明及服务清单为准。

## 隐私与反馈

- 发布 APK 不包含测试账号、密码、登录会话或个人截图；仓库不包含官方 APK、反编译产物或签名密钥。
- 客户端不保存登录密码，必要会话在本机加密保存。
- 学校部分接口使用 HTTP，业务负载加密不等同于 HTTPS 的传输保护。
- 反馈问题时请提供应用版本、系统版本、服务名称和复现步骤，并遮挡截图中的个人信息。不要公开账号密码或会话凭据。

本项目不是学校官方客户端，也不代表学校提供支持。功能依赖学校现有接口，后续适配进度以仓库更新为准。
